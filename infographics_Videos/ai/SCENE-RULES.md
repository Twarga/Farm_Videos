# Scene playbook — how the visuals are built

The channel does not use one visual style. It uses a small family of templates.
The main one for the new channel is **mint + dark teal + yellow**.

---

## 1. The visual identity

### Main look (mint / teal / yellow)

| Part | Value |
|---|---|
| Background | mint `#D7E6E6`, softer band `#BCD1D1` |
| Text | deep teal `#093532` |
| Accent | yellow `#FDCA3B` |
| Green | `#1C9639` |
| Red (warning / wrong) | `#B71F22` |
| Cards | white, rounded, thin outline, soft shadow |
| Photos | rounded corners, yellow tag, source credit |
| Maps | Morocco green, rival country red or blue, dashed route |
| Watermark | channel logo top-left or bottom-left |
| Section label | top-right, small, with a dot |

### Paper look (special episodes)

| Part | Value |
|---|---|
| Background | beige `#EAE4D5` |
| Teal | `#0D7673` |
| Yellow | `#FDCA3B` |
| Extras | tape corners, paper stamps, yellow tags |

### Type

- Bold Arabic sans, similar to Cairo, Tajawal or Almarai.
- Headline: 60–90 px at 1080p.
- Body: 36–48 px.
- Source: 20–24 px.
- Yellow highlight behind the key phrase only.
- Numbers are big: in a circle, a box, or a full-screen card.

### Layout

- One idea per screen.
- 3–5 elements maximum.
- Text right-aligned or centered.
- Leave breathing room; do not fill every corner.
- Every map or photo gets a source line.

---

## 2. The ten scene types

Use only these. They cover almost every moment in the 13 videos.

### 1. Hook card
- One big date or number + one short line.
- Example: “أكتوبر 2024” and “0.4%”.
- Motion: number counts in, text fades up.

### 2. Map scene
- Morocco outline or satellite image.
- Route line, pins, highlighted regions, country colors.
- Motion: slow zoom, route draws, pins pop, labels appear one by one.
- Always add the source.

### 3. Chapter card
- Huge number + chapter title.
- Example: “02 الكهرباء”, “06 وجه جمهوره”.
- Motion: wipe up from the bottom, number first, title second.
- Hold 2–4 seconds.

### 4. Photo card
- Rounded photo, tape or frame, yellow location tag.
- Motion: slide in, slow zoom, label pops.
- Source credit in the corner.

### 5. Stat card
- One number, one unit, one human meaning.
- Yellow circle or box.
- Motion: count up 0 → target, then the label lands.

### 6. Bar / progress chart
- 2–4 bars, years or categories.
- Motion: bars fill, numbers count, labels land last.
- Keep the chart simple; no 3D, no gridlines unless needed.

### 7. Comparison card
- A vs B, before vs after, Morocco vs another country.
- Two photos or icons, red X / green check.
- Motion: left side in, right side in, verdict last.

### 8. Diagram
- 4–6 icons connected by arrows: value chain, process, hierarchy.
- Motion: shapes appear one by one, arrows draw, labels appear.
- Example: phosphate → acid → fertilizer → battery.

### 9. Timeline
- Horizontal line with dated dots.
- Motion: line draws, dots pop, labels appear.
- Use for history and “from 2007 to today”.

### 10. Outro card
- The question + “comments” + two next topics.
- Channel logo and subscribe hint.
- Motion: simple fade/slide; no flashy effects.

## 3. From script line to scene

Every script beat becomes one scene. Use this recipe:

| Script beat | Scene | Motion |
|---|---|---|
| Date + surprising fact | Hook card | count-up + fade |
| “Where is this place?” | Map | zoom + pin |
| “How big is it?” | Stat card | count-up |
| “Compared to what?” | Comparison | left/right reveal |
| “How does it work?” | Diagram | build step by step |
| “When did it start?” | Timeline | line draw + dots |
| “Who said it?” | Document/logo card | slide in + highlight |
| “What happened next?” | Chapter card | wipe up |
| “What does it mean for you?” | Stat + photo | count-up + tag |
| “What should we explain next?” | Outro card | fade |

### Scene card template

```
SCENE 03 — map
Time: 1:20–1:45
Script: "..."
Visual: Morocco map, route from X to Y
Motion: zoom in, draw route, pin at Y
Assets: map, source credit
Audio: narration + quiet music
```

---

## 4. Motion rules

- One element at a time: headline → photo/card → label → number.
- Each element: 0.2–0.6 seconds, then hold.
- Numbers count up from 0.
- Bars fill from 0.
- Maps zoom slowly and draw routes.
- Photos get a slow zoom (3–8 seconds).
- Chapter cards wipe or slide up.
- Transitions: slide, fade, soft wipe. Glitch only for a topic change.
- No hard cuts inside an infographic scene.
- Motion follows the sentence: change the visual when a new idea starts.

### Pacing

- Infographic scenes hold for 25–100 seconds or more.
- The reference channel's average shot is long; it lets the narrator carry the scene.
- Documentary-style videos cut every ~4 seconds.
- Do not animate constantly. Let the scene breathe, then reveal the next element.

## 5. The 15-minute storyboard

Use this as the default skeleton.

| Time | Scene | Job |
|---|---|---|
| 0:00–0:20 | Hook card | date/number + surprise |
| 0:20–0:50 | Context map/photo | where and why now |
| 0:50–1:10 | Early CTA | like / comment / subscribe |
| 1:10–1:30 | Chapter 1 card | question |
| 1:30–4:00 | Map + stat + comparison | first answer |
| 4:00–4:10 | Chapter 2 card | next question |
| 4:10–6:30 | Stat + diagram | how it works |
| 6:30–6:40 | Chapter 3 card | next question |
| 6:40–9:00 | Timeline + document | history and proof |
| 9:00–9:10 | Chapter 4 card | next question |
| 9:10–11:30 | Map + comparison | scenarios / risks |
| 11:30–13:30 | Stat + photo | what it means for people |
| 13:30–14:30 | Turn | cost, risk, missing piece |
| 14:30–15:00 | Outro card | answer + comments + next topics |

Adjust the chapter count to 3–6. Keep the same rhythm.

---

## 6. Common mistakes

1. **Too many elements on one screen.** Use 3–5. One idea.
2. **Text that is too small.** If it cannot be read on a phone, it is too small.
3. **No source credit.** Every map and photo needs one.
4. **Constant motion.** Let the scene hold; reveal one element at a time.
5. **Wrong palette.** Stick to mint/teal/yellow for the main style.
6. **Mixing templates in one video.** Choose one format per video.
7. **Charts with too much data.** 2–4 bars, one message.
8. **No chapter cards.** Chapter cards are the skeleton of the video.
9. **A hook card that is just a logo.** The first frame must carry the fact.
10. **No outro question.** The ending must ask for the next topic.
