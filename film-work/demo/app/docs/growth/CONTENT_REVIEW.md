# SEO content maintenance

Review one small batch each month. A page is worth keeping only when it answers a distinct VPS question with current facts.

## Before editing

- Confirm the provider/offer is published and its price source is within the 14-day freshness window.
- Check the page has one clear search intent (provider plans, budget VPS, location, or workload).
- Keep the title, description, and first paragraph specific; do not repeat the same generic paragraph across providers.
- Link to the catalog, methodology, updates, and correction path where useful.

## After editing

- Run `npm run build`, `npm test`, and `npm test`.
- Compare organic clicks and offer clicks over 30 days, not vanity impressions alone.
- Record the URL, reason, source date, and expected signal in the weekly note.

Never change factual ranking inputs to improve search position. If a provider requests copy changes, require a source and keep the editorial decision independent.
