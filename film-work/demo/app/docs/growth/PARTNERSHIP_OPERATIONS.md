# Partnership operations

Provider affiliate work stays in the provider-affiliate record, separate from editorial ranking.

Track for each provider: program availability (`none`, `closed`, `public`, `application`, `partner-only`), project status, signup URL, network, commission notes, application date, approval date, last checked date, and a short operator note. Use `lastCheckedAt` as the next follow-up anchor; do not treat a missing program as a reason to change a VPS score.
