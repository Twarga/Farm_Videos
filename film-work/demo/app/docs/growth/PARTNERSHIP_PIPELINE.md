# Partnership outreach pipeline

Use the provider affiliate record as a tiny CRM—no separate paid tool is needed.

| Stage | Owner action | Required fields |
|---|---|---|
| Researching | Find the official partner/contact page | provider, source URL, notes, last checked |
| Contacted | Send a short, honest introduction | contact date, contact URL/email, message note |
| Waiting | Set a follow-up date | follow-up date, channel, last response |
| Approved | Store terms without changing ranking | approval date, network, cookie/commission notes, tracking URL |
| Paused/closed | Stop outreach and remove public affiliate link | status, reason, checked date |

Follow up once after 7–14 days, then pause. Never promise a ranking position. Keep provider corrections in the correction workflow, even when a partnership exists.
