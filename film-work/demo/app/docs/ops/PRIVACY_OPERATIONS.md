# Privacy request handling

The public site does not require accounts and analytics uses a rotating anonymous token. Correction submissions may include an optional email so the owner can reply.

## Request path

1. Ask the requester to email `privacy@bestvpsforme.com` from the address they used (if any) and include the request type: access, correction, or deletion.
2. Verify ownership with the minimum reasonable evidence; never ask for a password or identity document by email.
3. Search the audit log by correction ID/email hash, export only the matching records, and redact unrelated providers or visitors.
4. Delete optional contact data and associated correction payload when deletion is approved; retain a minimal compliance note without the original message.
5. Respond within 30 days and record the date/action, not the sensitive contents.

Do not promise deletion of aggregate, already-published metrics that contain no direct identifier. Follow the public `/privacy` notice and escalate security concerns to `security@bestvpsforme.com`.
