# bestvpsforme — start here

Full research: [PRODUCT_STRATEGY_AND_RESEARCH_2026-10-23.md](PRODUCT_STRATEGY_AND_RESEARCH_2026-10-23.md).
Research date: 23 October 2026. Proposed scope, not an implementation promise.

## The big idea

**One trusted VPS comparison engine. Website first. Developer and AI access later.**

The crab finds a suitable shell. The evidence explains why.

## V1 — launch the remade website

**Goal: help someone choose a server.**

- New crab-based logo and living TwargaOps art direction.
- Keep useful catalog, filters, compare and honest offer receipts.
- Meaningful motion; prices remain immediate and readable.
- Optional confirmed plan watch, only if real alerts work. Otherwise label the signup as an alerts-launch waitlist.
- No CLI, MCP, payments or autonomous server buying yet.

**Money:** labelled affiliate links. Non-partners stay eligible for ranking.
**Before launch:** refresh facts, approve the visual direction, finish accessibility and target-server checks.

## V1.5 — give people a reason to return

**Goal: tell them when something genuinely changes.**

- Reviewed price-change alerts.
- Honest price history, with gaps and assumptions visible.
- Saved shortlists and a small evidence-based workload guide.

**Money:** continue affiliates. Learn whether anyone wants repeated paid monitoring.

## V2 — CLI and AI-agent access

**Goal: compare inside the tools people already use.**

1. Versioned read-only API: one source of truth.
2. Thin CLI: useful terminal output and JSON.
3. MCP adapter: agents can find, compare and explain dated offers.

Build adapters in the order real pilot users request.
**No cloud keys. No automatic purchases. No separate AI ranking.**

**Money:** affiliate human handoffs where explicitly permitted; test paid API volume/support separately.

## V3 — professional and partner product

**Goal: recurring value for repeat buyers and integrators.**

- Agency reports, team shortlists and monitoring.
- Higher API quotas, history exports and webhooks.
- Properly licensed data partnerships.

**Money:** paid pilots, then subscriptions if customers demonstrate demand.

## Three research findings that matter

- Hetzner says its old referral-credit program is discontinued. Do not forecast that income.
- DigitalOcean's advertised affiliate percentage is not proof of lifetime recurring commission; program terms govern channel permissions and payouts.
- Public cloud datasets may restrict competing commercial use. Check the exact license before building on one.

Sources, caveats and links: full report sections 12 and 19.

## What to do now

**Freeze V1. Design one homepage and one catalog screen in the crab world.**

Keep the existing backend unless a real technical constraint justifies changing it.
Later CLI/MCP scope should not delay the website launch.
